这里记录博客本身的搭建与改动。

技术栈

  • 框架：Hexo 8
  • 主题：Butterfly 5（npm 安装，Dependabot 自动提升级 PR）
  • 托管：GitHub Pages，域名 032.im
  • 发布：push 到 main 后由 GitHub Actions 自动构建并发布
  • 评论：Giscus（GitHub Discussions）
  • 追番：hexo-bilibili-bangumi（数据来自 Bangumi）

更新日志

2026-11 · 翻新

  • 主题从 Butterfly 4.9 升级到 5.7，改为 npm 依赖，不再把整个主题放进仓库
  • 开启站内搜索（右上角放大镜）

  • 「听音记录」「手办展示」改为系列，文章页侧栏可直接跳转同系列文章
  • 全站图片转为 WebP，图片总体积从约 19 MB 降到约 6 MB
  • 新增 404 页面、文章字数与阅读时长、旧文过期提醒
  • 重写关于页，清理测试文章与不再使用的配置
